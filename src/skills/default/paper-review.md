# 论文审稿

按 NeurIPS 审稿表写一份审稿，不是再写一篇摘要。只依据 PDF 抽出的文字。某一页没有可提取的文字，在限制里记下页码，并把信心分压低。不要用记忆补实验、引用或没读到的章节。摘要栏不要粘贴原文 abstract。

1. 用户没给 PDF 路径时，先用 glob 查找 `**/*.pdf`。只有一个就用它；有多个就列出路径，问要审哪一篇。
2. 用 search_notes 查是否已有同题审稿笔记。已经有就停下，给出相对路径，不要覆盖。
3. 用 read_pdf 从第 1 页读起，每次都传 limit 4。结果写着还有剩余，就用它给的 offset 再读，limit 仍是 4。摘要、方法、实验、结论、作者自述的限制都读完后再写。不要只根据前几页打分。
4. 用 create_note 新建审稿笔记。路径用短标题加 `-review`，例如 `Papers/ppo-review.md`。用户确认后才会写入。若结果写路径已存在，换一个未占用的短路径再 create_note，不要改原文件。
5. 回答里写上新笔记的相对路径，以及 Overall 和 Confidence。

笔记第一行是 `# Review: ` 加上论文标题。标题下写被审 PDF 的相对路径。分数必须和正文优缺点一致；说没新颖性时，只引用 PDF 里出现的前作名字，不要编库外论文。每一节写成可读段落，空标题不算完成。原文没写的项写 `原文未提及`。

## 摘要

用自己的话写贡献。这里不批评。

## 优点

按接受的理由写。覆盖质量、清晰、重要性、原创性。质量：论证和实验是否撑得住声称。清晰：组织、能否复现。重要性：别人会不会用。原创性：不一定要全新方法，把已有方法看清楚也算。

## 缺点

按拒稿的理由写。同样覆盖这四维。要具体到方法名、数据集、缺的对照或没做的消融。笼统「实验不够」不算。

## 分数

各 1–4（4 优秀 / 3 良好 / 2 一般 / 1 差）：

- 质量：
- 清晰：
- 重要性：
- 原创性：

Overall 1–6：6 强收 / 5 收 / 4 边缘收 / 3 边缘拒 / 2 拒 / 1 强拒。4 和 3 少用。

Confidence 1–5：5 很熟相关工作且核对了细节；3 可能没看懂部分；1 是猜的。空白页多、公式读不出时不要高于 3。

## 问题

3–5 个作者答了就能改分数的问题。写清怎样答会加分或减分。若建议新实验，说明它回答什么问题。

## 限制

作者是否老实写了不足和潜在负面影响。写了就 `是`；没写就给出该补什么。不要因为作者承认限制而扣分。

## 伦理

PDF 里若有明显伦理问题再写；没有就 `未见`。
