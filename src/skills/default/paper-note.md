# 论文笔记

只写 PDF 里抽出的文字。某一页没有可提取的文字，就在限制里记下页码。不要用记忆补上作者、数字、结论或没读到的章节。

1. 用户没给 PDF 路径时，先用 glob 查找 `**/*.pdf`。只有一个就用它；有多个就列出路径，问要读哪一篇。
2. 用 search_notes 查同题笔记。已经有就停下，给出相对路径，不要覆盖。
3. 用 read_pdf 从第 1 页读起，每次都传 limit 4。结果写着还有剩余，就用它给的 offset 再读，limit 仍是 4。封面、摘要、方法、实验、结论都读完后再写。不要只根据前几页交稿。
4. 用 create_note 新建笔记。路径用短标题，例如 `Papers/ppo.md`。用户确认后才会写入。若结果写路径已存在，换一个未占用的短路径再 create_note，不要改原文件。用户要求覆盖时，说明现在不能覆盖，并给出已有路径。
5. 回答里写上新笔记的相对路径。

笔记第一行是论文标题（`# …`）。标题下若 PDF 里有作者、会议或期刊、年份，写成一行元信息，没有就省略。后面按下面各节写。每一节写成可读的段落，保留原文里的任务名、方法名、数据集、指标和数字。一句话带过、只列空标题，都不算完成。某一节原文确实没写，写 `原文未提及`，不要删节、也不要编。

## 一句话

这篇论文要解决什么、提出了什么。

## 问题

任务设定、现有方法卡在哪里、本文的目标。把动机和要优化的对象写清楚。

## 方法

核心想法、和前人差在哪、关键模块或公式（按原文抄，不要自己推）、训练或推理怎么走。专有名词第一次出现时附原文术语。

## 实验

用了哪些数据、对照、指标、主要设置。数字跟原文走。

## 结果

主结果写到具体数字和对照对象。有消融、分析或案例，单独写清它们说明了什么。

## 限制

作者承认的不足、失败情况，以及因空白页读不到的内容。

## 可接着读

原文指向的前作、代码或数据；没有就写 `原文未提及`。
