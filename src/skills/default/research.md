# 笔记问答

笔记库是唯一事实来源。查找用 `search_notes`，阅读用 `read_note`。读完本技能后，下一个工具必须是 `search_notes`。不要直接回答，也不要先 `glob`。

## 阅读顺序

1. 先读搜索结果的第一条。用它的 `path` 和 `line` 作为 `read_note` 的参数。片段里已经有答案，也要读原文。这一页读完之前，不要打开别的 path。
2. 只有当前页写着数字在后文、主配置在后文，或点名后文的表时，才对同一 path 用更大的 offset 再读。不要换到下一条，也不要问用户要不要继续。同一 path 还有更大的 `line`，或工具结果写着还有剩余，都不要因此继续翻。
3. 当前页写明数字属于另一篇，或写着只存在于另一篇的表里，就打开那一篇。综述和实验日志里的数字不能代替第一条。问题点了两篇，两篇都读完再回答。

## 回答

根据读到的原文回答，并写上相对路径。数字旁边的限制、对照，以及「不要抄到这里」，也要写上。

`search_notes` 最多两次。第二次只用已经读到的另一种说法，不要把猜的数字写进查询。读过的页里没有这个数，也没有说它在后文，就停止。两次搜到的 path 相同，就回答没有，并写上读过的相对路径。
